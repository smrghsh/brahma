To feel the multiplayer: open the same app in two windows and click Join Session in both — each room is its own shared space. These builds connect to ws://localhost:8080; npm run hub starts that relay for you, or run npx brahma-xr-server yourself. Testing from a headset or another device needs https — use each app's dev server (npm run dev) instead.
