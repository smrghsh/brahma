Brahma

Open source WebXR library for collaborative scientific visualization

GitHub npm install brahma-xr Docs

Brahma creates a real-time data loop between clients and server — the moment the connection is made, the whole system comes alive. Unlike proprietary engines such as Unity or Unreal, it requires only standard web development practices: HTML, JavaScript, and Three.js. Designed for researchers, educators, and developers who need fast iteration, shareable URLs, and broad cross-platform reach — from headsets to mobile browsers.

Core Features

🌐

Multi-user by default

WebSocket-based avatar embodiment at ~30fps. Every user gets a unique ID and color via REST API.

🥽

Cross-platform XR

Runs identically on Meta Quest, Apple Vision Pro, Valve Index, Varjo, mobile, tablet, and desktop.

🔗

Shared state

Interface state synchronized via REST + WebSocket. Everyone sees the same data at the same time.

📡

Telemetry

Log user poses and events to CSV for HCI research, proxemics studies, and interaction analysis.

🖐️

Accessible input

Grab-and-pull locomotion and raycasting via controller, hand tracking, mouse, or eye-tracking.

🚀

No build lock-in

Peer dependency on Three.js. Works with Vite, Rollup, or direct script import. Just standard web dev.

Quick Start

# Install
npm install brahma-xr three

# Client
import { Brahma } from 'brahma-xr';
import * as THREE from 'three';

const brahma = new Brahma();

# Server
import { BrahmaServer } from 'brahma-xr/server';

const server = new BrahmaServer();

# Run locally
npm install && npm run build && npm run server
